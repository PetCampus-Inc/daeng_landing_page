# 랜딩페이지 이미지

`next/image`(문자열 src)로 참조되며, 파일이 아직 없어도 빌드는 통과한다.
실제 파일을 이 폴더에 같은 이름으로 넣으면 자동 반영된다.

## 히어로 (S-02)

| 파일 | 용도 | 권장 크기(표시의 1.5배 이상) |
|---|---|---|
| `hero-desktop.png` | 데스크탑 우측 이미지 패널 (세로 4:5) | 1200 × 1500 |
| `hero-mobile.png` | 모바일 전체 배경 (텍스트가 위에 올라감) | 1125 × 2000 |

- 보호자와 반려견 실사. 모바일용은 상단·좌하단에 텍스트가 겹치므로 해당 영역은 여백 위주로.
